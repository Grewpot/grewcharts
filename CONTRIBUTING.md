# Contributing to GrewCharts

Thank you for helping improve GrewCharts! 🚀

## Current contribution scope

Community contributions are currently focused on:

## `grewcharts.html`

Welcome contributions include:

- Bug fixes
- Footprint and visualization improvements
- Calculation improvements
- Performance improvements
- WebSocket and market-data handling improvements
- UI/UX improvements inside the terminal
- Accessibility improvements
- Testing and bug reports

## Please do not modify without prior discussion

The following files are maintained separately:

- `index.html` — landing page and marketing
- `vercel.json` — deployment configuration
- Project branding and legal files

## Workflow

1. Fork the repository.
2. Create a branch such as `feature/...` or `fix/...`.
3. Make your changes to `grewcharts.html`.
4. Test your changes locally in a browser.
5. Open a Pull Request.
6. Clearly explain what changed and why.

## Important

Do not push directly to `main`. All production changes should go through Pull Requests and maintainer review.

Because GrewCharts is experimental, changes affecting market calculations or displayed data should clearly describe their assumptions and limitations.

Thank you for helping build GrewCharts in the open.
