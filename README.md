# GrewCharts

> See what the candle doesn't show.

GrewCharts is an experimental browser-based market analysis project exploring footprint visualization, live trades, volume, and order-book activity.

## 🚧 Experimental status

GrewCharts is under active development. Calculations, visualizations, and displayed market data may contain errors, delays, inaccuracies, or unexpected behavior.

**Do not use the current version as the basis for trading or investment decisions.** Verify market information independently.

## Project structure

- `index.html` — GrewCharts landing page and project presentation
- `grewcharts.html` — GrewCharts terminal and the current focus for community contributions
- `.github/` — contribution and Pull Request templates

## 🤝 Contributing

Community contributions are currently focused on **`grewcharts.html`**.

Please avoid modifying `index.html`, branding, or deployment configuration unless the change has been discussed with the project maintainer.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow.

## Deployment

This repository can be connected directly to Vercel. Changes merged into the production branch can deploy automatically, while Pull Requests can receive preview deployments.
